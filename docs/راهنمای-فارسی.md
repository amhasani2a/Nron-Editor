# راهنمای ساده Nron ۰.۲

## قبل از نصب
اگر نسخه قبلی را دارید، از **تنظیمات ← گرفتن پشتیبان** یک فایل JSON بگیرید.
APK تحویلی با امضای آزمایشی ساخته شده، نه کلید انتشار شما؛ ممکن است روی نسخه‌ای
با امضای متفاوت نصب نشود. در این حالت **اول پشتیبان بگیرید**، بعد نسخه قبلی را
حذف و نسخه آزمایشی را نصب کنید. حذف برنامه اطلاعات محلی آن را پاک می‌کند.

## اندروید
فایل APK برای گوشی‌های **arm64** و اندروید **۸ به بعد** است. این نسخه برای تست
مستقیم است؛ برای انتشار عمومی، کلید ثابت خودتان را در GitHub تنظیم کنید.
رابط اصلی این ادیتور با HTML/CSS سبک داخل Tauri است؛ بازنویسی Kotlin/Compose
نیست. هسته Rust و پوسته اندروید بومی‌اند. پروژهٔ ویان تغییری نکرده است.

## ویندوز
ZIP ویندوز را کامل استخراج کنید و `Nron-Editor.exe` را اجرا کنید.
این خروجی **پرتابل x64** است، نه نصب‌کننده MSI. برای اجرا به Microsoft Edge
WebView2 Runtime نیاز دارد. فایل امضای تجاری Authenticode ندارد؛ ناشناس بودن
ناشر در هشدار ویندوز طبیعی است. اجرای واقعی روی ویندوز در این محیط لینوکسی
آزمایش نشده است. نصب‌کنندهٔ عادی را از workflow ویندوز بگیرید.

## ابزارهای تازه کجا هستند؟
- دکمه **⌘** بالای صفحه یا میان‌بر **Ctrl/Cmd + Shift + P**: فهرست ۵۰ فرمان.
- فرمان تبدیل متن، اول پیش‌نمایش می‌دهد؛ بعد از تأیید، کل متن را جایگزین می‌کند.
  قالب‌بندی تبدیل به متن ساده می‌شود. نسخه قبلی در تاریخچه می‌ماند.
- پلاگین‌ها: فرمان **مدیریت پلاگین‌ها**؛ نمونه آماده در `plugins/persian-cleanup.json`.
  این پلاگین‌ها تبدیل متن‌اند، نه اجرای آزاد کد و دسترسی به سیستم.
- به‌روزرسانی: **تنظیمات ← بررسی به‌روزرسانی GitHub**.
- آمار، هدف کلمات، قالب جلسه/روزانه/طرح نوشته و گزینه‌های نمایش در همان فهرست هستند.

## چطور روی GitHub بیلد بگیرم؟
۱. ZIP سورس را استخراج کنید.
۲. **محتویات** پوشه `Nron-Editor` را در ریشه ریپو قرار دهید، نه خود فایل ZIP را.
   پوشه مخفی `.github`، فایل `package-lock.json` و `src-tauri/Cargo.lock` هم باید باشند.
۳. وارد تب **Actions** شوید.
۴. برای APK تست: **Android test APK ← Run workflow**.
۵. برای ویندوز، مک، لینوکس و اندروید: **Cross-platform builds ← Run workflow**.
۶. پس از اتمام، پایین صفحه اجرای workflow قسمت **Artifacts** را دانلود کنید.
۷. برای انتشار رسمی با tag مثل `v0.2.1` اقدام کنید؛ خروجی ابتدا Draft می‌شود
   تا خودتان آن را بررسی و منتشر کنید. نسخه پروژه را هم قبل از tag هماهنگ کنید.

## به‌روزرسانی رسمی
- کلید خصوصی و رمز را داخل سورس، ZIP یا چت نگذارید.
- برای اندروید، Secrets چهارگانه در `docs/UPDATES.md` را با کلید ثابت خودتان تنظیم کنید.
- برای نصب خودکار دسکتاپ، کلید امضای updater و کلید عمومی لازم است.
- این بیلد بدون کلید ناشر، بررسی نسخه و رفتن به صفحه دانلود را دارد؛ نصب خودکار
  امضاشده فقط پس از تنظیم کلید و انتشار واقعی فعال می‌شود.
- اندروید نصب بی‌اجازه ندارد؛ تأیید نصب سیستم‌عامل همچنان لازم است.

## خروجی متن
Word واقعاً DOCX است، با قالب‌بندی پایه؛ تبدیل کامل صفحه‌آرایی HTML/جدول/تصویر
به Word نیست. EPUB بسته ZIP معتبر با XHTML و تصاویر raster داخلی پشتیبانی‌شده
است. برای حفظ دقیق‌تر صفحه و تصاویر، خروجی HTML را انتخاب کنید.
**چاپ / PDF** در دسکتاپ از پنجره چاپ استفاده می‌کند؛ در اندروید HTML آماده چاپ
ذخیره می‌کند تا در مرورگر به PDF تبدیل کنید. فایل HTML با پسوند PDF تحویل نمی‌دهد.

## تغییرات نسخهٔ ۰.۳
- بالای صفحه «＋» سند جدید می‌سازد. آیکن کتابخانه کنار آن، همهٔ اسناد، بایگانی و مجموعه‌ها را باز می‌کند.
- علامت «−» روی تب سند، آن را بایگانی می‌کند؛ حذف نمی‌کند. در کتابخانه، «بایگانی» را انتخاب و سند را بازگردانی کنید.
- برنامه از تازه‌ترین سند ایجادشدهٔ بایگانی‌نشده باز می‌شود.
- در کتابخانه «قالب‌ها» را بزنید. می‌توانید سند خودتان را قالب کنید یا قالب JSON وارد/دریافت کنید. قالب همیشه در سند تازه اعمال می‌شود.
- تنظیمات ← «ظاهر، فونت‌ها و قالب‌های شخصی»: ده فونت اضافه، فونت شخصی، شش ظاهر و کاهش حرکت‌ها.
- برای پومودورو در منوی موبایل روی پومودورو بزنید؛ زمان نوشتن/استراحت را تنظیم کنید و شروع را بزنید. پایان زمان در پس‌زمینه اعلان تضمین‌شده ندارد.
- پیش از نصب یا حذف نسخه قبلی پشتیبان بگیرید. برای حفظ فونت شخصی در بکاپ، تیک مربوطه را فعال کنید.
- تاریخچه برای مصرف حافظه محدود است؛ متن فعلی کوتاه نمی‌شود، ولی نسخه‌های قدیمی تاریخچه ممکن است پاک شوند. بکاپ مستقل را فراموش نکنید.
- خروجی HTML و EPUB فونت فارسی همراه دارند؛ Word متن راست‌به‌چپ دارد ولی فونت محلی سیستم مقصد ممکن است جایگزین شود. چیدمان بسیار پیچیده و همهٔ کتاب‌خوان‌ها تضمین نشده‌اند.

### ساخت قالب برای دیگران
یک فایل با پسوند `.json` و ساختار زیر بسازید و از بخش قالب‌ها وارد کنید:
```json
{"name":"یادداشت پروژه","content":"<h1>پروژه</h1><h2>قدم بعدی</h2><p></p>"}
```
قالب شامل متن و قالب‌بندی مجاز است، نه اسکریپت. برای اشتراک‌گذاری قالب شخصیِ ساخته‌شده در برنامه، «دریافت JSON» را بزنید. خروجی HTML/EPUB برای ثبات نمایش از وزیر همراه استفاده می‌کند؛ فونت شخصیِ انتخاب‌شده الزاماً فونت خروجی نیست.
