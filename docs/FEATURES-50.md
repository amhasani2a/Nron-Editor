# ۵۰ فرمان پیاده‌سازی‌شده

فرمان‌های تبدیل متن روی تمام سند اعمال می‌شوند، پیش‌نمایش دارند و قالب‌بندی را
به متن ساده تبدیل می‌کنند. نسخه قبلی پیش از اعمال در تاریخچه ثبت می‌شود.
